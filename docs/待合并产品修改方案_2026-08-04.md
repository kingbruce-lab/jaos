# 京奥智库入库审核简化方案

版本：2026-08-04  
状态：已于 2026-08-06 实施  
实施结果：常规资料采用“预览内容 → 确认入库”的一键确认流程；公司介绍等“当前口径”在确认入库后仍需由创始人单独发布为当前版本。

## 1. 本轮已确认方向

- 审核人员必须先看见资料内容，不允许盲审。
- 前台采用“一屏预览、一键确认”，后台继续保留元数据、权限、版本和审计记录。
- 创始人拥有全部资料的最终确认权。
- 部门负责人可确认本部门 L1-L2 普通资料。
- L3-L4、公司级口径、跨部门资料和当前版本替换由创始人确认。
- 普通项目资料确认后进入历史知识库；公司介绍等常青资料才使用“当前版本”概念。
- 测试资料与正式审核队列隔离。

## 2. 统一预览能力

审核卡必须提供可见内容和原件入口：

- PDF：原页预览。
- PPTX/DOCX：引用版 PDF 原页预览。
- TXT/Markdown：正文预览。
- XLSX/XLSM：工作表、表格和分页预览。
- PNG/JPG/JPEG/WebP：原图预览和 OCR 文字。
- 视频：鉴权在线播放、封面图、文件格式、时长和文件大小。
- 所有类型：提供“查看原件/下载原件”。
- 解析失败或源文件失联：禁止确认并显示具体原因。

## 3. 视频首轮边界

### 首轮纳入

- 入库格式：MP4、MOV、M4V、WebM；其他格式进入待处理列表。
- 浏览器优先直接播放 MP4（H.264 视频 + AAC 音频）。
- 不兼容编码由后台生成低码率 MP4 预览副本，原件不修改。
- 播放接口必须经过登录鉴权、部门与密级检查，并支持 HTTP Range，便于拖动进度条。
- 登记基础元数据：文件哈希、格式、编码、分辨率、时长、大小、所属项目、部门、密级和版本。
- 自动生成封面缩略图；审核页可在线播放和下载原件。

### 暂不纳入首轮

- 视频语音识别和字幕生成。
- 按视频内容进行语义检索。
- 画面人物、Logo、活动场景识别。
- 视频内容引用到具体时间点。

上述能力继续保留在二期。真实视频数量和使用频率足够后，再决定使用本地 faster-whisper、内网 GPU 或授权云端转写。

## 4. 简化后的审核路由

| 资料范围 | 审核人 | 确认结果 |
|---|---|---|
| 部门内 L1-L2 项目资料 | 对应部门负责人 | 确认并进入历史知识库 |
| 部门内当前制度或能力资料 | 对应部门负责人 | 确认并设为部门当前版本 |
| L3-L4 敏感资料 | 创始人 | 创始人确认后按权限入库 |
| 公司介绍、资质、品牌口径、核心成绩 | 创始人 | 确认并设为公司当前版本 |
| 跨部门或归属冲突资料 | 创始人 | 确认、重新分派或退回 |
| 上传员工 | 无发布权 | 上传并补充说明 |

审核权限必须由登录账号的角色、负责部门、密级上限和资料归属共同计算，不能采用上传人自行声明的权限。

## 5. 审核页面交互

- 左侧或上方展示完整预览，右侧或下方展示 AI 预填元数据。
- 只突出显示缺失字段、冲突字段和低置信度字段。
- 普通资料提供“确认并入库”“退回修改”。
- 常青资料提供“确认并设为当前版本”“退回修改”。
- 创始人可直接完成确认，不要求先提交建议再由自己审批。
- 普通 L1-L2 操作不要求手工输入确认短语。
- 替换公司级当前版本、L3-L4、批量操作等高影响动作保留二次确认弹窗。
- 后台继续分别记录元数据确认、审核人、发布时间、替代范围和历史版本，不因前台一步操作而减少审计。

## 6. 集中实施前的真实流程复盘

员工完成首批材料上传后，按以下路径跑一遍：

1. 员工上传不同格式资料，至少覆盖 PDF、PPTX、DOCX、XLSX、图片和视频。
2. 系统扫描、去重、解析、预填元数据并分派审核人。
3. 部门负责人审核本部门 L1-L2 资料。
4. 创始人审核公司级、跨部门及 L3-L4 资料。
5. 检查历史检索、当前事实检索、引用跳转、原件预览和权限隔离。
6. 集中收集所有意见，冻结最终修改范围后一次性开发、测试和发布。

## 7. 暂定验收标准

- 支持格式的审核项 100% 可预览或明确说明失败原因。
- 无法预览、源文件失联或解析失败的资料不能被确认。
- 部门负责人不能看到或确认其他部门受限资料。
- 部门负责人不能确认 L3-L4、公司级或跨部门资料。
- 创始人可以在一个审核页面完成任意资料的检查与合法确认。
- 视频可在桌面端和手机端播放、暂停、拖动进度，并且未授权用户无法通过直接链接访问。
- 审核、退回、发布和版本替代均有完整审计记录。
