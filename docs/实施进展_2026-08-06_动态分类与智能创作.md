# 京奥智库实施进展（2026-08-06：动态分类与智能创作）

## 本轮结论

已把知识库分类从固定业务线改为创始人可维护的动态分类，并把员工端的“提案共创”改为通用“智能创作”。员工现在可以用自然语言说明要写什么，系统自动检索其有权访问的智库资料，生成可编辑初稿并保留文件、版本和页码来源。

## 已上线功能

1. 动态资料分类
   - 创始人可新增、重命名、停用和重新启用分类。
   - 电竞培训、电竞青训、电竞战队、电竞赛事、场馆运营、公司公共资料仅作为首批默认值，不再写死为产品结构。
   - 分类使用稳定内部键；改名不影响历史项目、权限、检索和引用。
   - 上传、员工权限、审核元数据、搜索和智能创作统一读取服务端分类。

2. 通用智能创作
   - 一个自由输入框，不再要求员工填写固定 Brief，也不再设置同事共创流程。
   - 可选资料分类和“当前资料 / 历史资料 / 全部资料”范围。
   - 只检索当前员工有权限查看、原件在线且密级允许的资料。
   - L1–L2 证据可调用 `grok-4.5`，失败时回退 `deepseek-v4-flash`；L3–L4 默认只在 NAS 本地整理。
   - 事实保留 `[S#]` 引用；右侧列出文件名、版本、页码和原页预览入口。
   - 生成结果可继续编辑并一键复制。

3. 员工直接上传
   - Web 新增“资料上传”，支持电脑和手机多选文件、进度显示、资料分类和密级选择。
   - 单文件上限 2 GiB，公网 Nginx 与 Web 代理超时已同步放宽。
   - 文件进入 `99_AI入库待审核`，不会自动成为正式知识；仍需管理员确认元数据与入库。
   - NAS 正式资料目录保持只读，Agent 只有待审核目录写权限。

4. Codex Skill 同步升级
   - Skill 先调用 `/v1/categories` 获取当前有效分类，不再使用固定业务线枚举。
   - 新增 `categories` 与 `writing` 命令。
   - 自由写作成为默认员工工作流；固定八页培训提案只保留为明确请求时的兼容能力。
