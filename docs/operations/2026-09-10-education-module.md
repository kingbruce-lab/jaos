# 星曜托管教培模块

## 范围

- 账号管理新增 `education`（教培），应用权限为 employee；创建及更新账号均强制资料密级 L1。
- 独立 `/v1/pm/education` API 和 `education_cohorts`、`education_cash_entries` 表，不借用普通业务项目权限。
- 教培员工仅管理本人登记班期；L5 管理可维护全部；L4/L5 财务只读；其他角色拒绝访问。
- 月度班期保存招生人数、客单价、起止日期、备注；收支按明细追加并可修正。
- 预计收入为人数乘客单价；实际收支和结余从明细汇总。累计人数为各期人次相加。
- 不将手工教培记录自动插入银行流水，避免重复计账。
- POST 使用客户端 UUID 防止重试重复计账；修正使用版本校验和数据库行锁；写入与审计同一事务。
- 不提供删除入口，不迁移或覆盖历史业务项目。
