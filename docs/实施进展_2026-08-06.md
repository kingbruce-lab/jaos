# 京奥智库实施进展（2026-08-06）

## 本次完成

- 入库审核前台简化为“预览内容 → 确认入库”。创始人和资料管理员均可一键确认自己权限范围内的资料。
- 元数据修改改为可选动作；保存后会在确认入库时一并采用。
- PDF、PPTX/DOCX 引用版 PDF、图片、TXT/Markdown、XLSX/XLSM 支持审核预览；所有格式保留查看或下载原件能力。
- 原件失联、内容哈希变化、解析失败或没有可预览内容时禁止确认，并给出明确原因。
- 候选资料不再参与员工检索；确认后标记为 `approved`，进入有权限的历史知识检索。
- 公司介绍等当前口径仍采用两层状态：先一键确认入库，再由创始人单独发布为 `current`，旧版转为历史。
- 每次预览、确认和发布均保留操作者、资料 ID、状态变化和源文件校验结果的审计记录。
