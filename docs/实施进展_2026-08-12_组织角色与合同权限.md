# 京奥智库实施进展：组织角色与合同权限

日期：2026-08-12

## 组织角色

账号新增独立的 `organization_role` 字段，供京奥智库以及后续财务、项目管理、人事系统共同使用。界面只显示以下五类组织角色：

| 组织角色 | 智库系统权限 | 普通业务资料检索 | 合同档案 |
| --- | --- | --- | --- |
| 行政 | 资料审核与治理 | 最高 L3 | 检索行政、业务合同；可上传合同 |
| 人事 | 普通使用 | 最高 L3 | 仅检索人事合同，不可上传 |
| 业务 | 普通使用 | 按账号密级 | 不可进入或检索合同档案 |
| 财务 | 普通使用 | 按账号密级 | 不可进入或检索合同档案 |
| 管理 | 账号与系统管理 | 按账号密级 | 按密级检索全部合同；管理+L5可上传 |

组织角色和资料密级是两个独立维度。行政、人事账号即使具有 L4/L5 密级，普通智库检索仍在 SQL 召回前限制为 L1–L3；其 L4/L5 密级只在合同档案等独立高密级模块中生效。

## 兼容迁移

生产库启动时自动增加组织角色字段并迁移已有账号：

- 创始人 → 管理
- 资料管理员 → 行政
- 业务负责人、员工、旧策划角色 → 业务

原有系统权限仍作为内部访问权限保留，不在账号界面显示。迁移不修改用户名、密码、可见密级、登录会话或历史审计主体。

## 权限硬约束

- `/v1/contracts/uploads` 在服务端仅放行行政，或同时满足 `organization_role=management` 与 L5 的账号；前端隐藏不能替代后端鉴权。
- 人事、业务、财务以及非 L5 管理账号上传合同均返回 403，且不会在 NAS 创建文件。
- 合同检索同时执行“组织角色白名单 + 密级上限”：行政仅行政/业务合同，人事仅人事合同，业务和财务无任何合同权限，管理可按密级检索全部合同。
- 行政作为唯一上传与审核角色，可预览其负责审核的合同原件；这不扩大其合同检索范围。
- 普通资料检索对行政、人事采用 L3 上限，关键词与向量两条召回链路使用相同的检索前过滤条件。
