## 3. 用户需求落地情况

### 3.1 文件目录与知识分类可自定义

已完成。前端和 API 不再把“电竞青训、培训、战队”等写死为唯一目录。管理员可以创建、改名、排序、停用知识分类；员工上传时按本人有权限的当前分类选择，历史稳定 key 保证引用和权限不会因改名失效。

首批 6 个分类只是初始化数据：电竞培训、电竞青训、电竞战队、电竞赛事、场馆运营、公司公共，可随业务调整。

### 3.2 创作功能改为自由调用智库

已完成。员工无需进入固定的 Brief、目录、逐页提案和同事共创流程，可直接：

1. 输入任意写作任务和当前草稿；
2. 指定或不指定知识分类；
3. 检索有权限的正式资料；
4. 将证据连同文件名、版本和页码插入写作上下文；
5. 生成或改写材料，并保留来源引用。

固定“提案共创”能力仍可作为以后按需工作流存在，但不再是员工写材料的必经入口。
