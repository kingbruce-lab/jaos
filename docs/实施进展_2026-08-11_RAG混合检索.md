# 京奥智库 RAG 混合检索实施进展（2026-08-11）

## 已上线结论

- Embedding模型正式锁定为`gemini-embedding-2`，向量维度3072。
- L1与L2允许通过OriginGame网关生成向量；L3与L4保持0向量、0出网。
- 已完成1552个有效文本块的首轮索引：L1为43个，L2为1509个。
- 不使用Rerank，也不额外部署向量数据库。向量保存在PostgreSQL/pgvector中。
- 检索顺序固定为：登录身份 → SQL密级过滤 → 结构化/全文/向量并行召回 → RRF融合 → 引用封装。
- 新文件审核入库后，由夜间入库容器自动增量建立符合密级规则的向量。

## 本轮结构优化

解析后的文本块改为结构感知切分：

- PPT尽量保持同一页内的形状文本和备注边界；
- Word优先按段落切分；
- Excel优先保持完整行，不把一行表格从中间截断；
- 超长单元再按中英文句末切分；
- 重叠部分携带完整的尾部单元，不使用任意字符截断。

向量输入增加文件名和章节上下文，但向员工展示的引用仍保持原始摘录和页码，不污染证据文本。
