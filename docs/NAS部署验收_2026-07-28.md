## 公网入口防护验收

浏览器业务请求通过 Web 的 `/api/kb` 同源转发到 Docker 内部 Agent，不把
局域网 Agent 地址暴露给员工浏览器。本地真实链路已验证登录、读取身份和
搜索均返回 200。

NAS Web 实测：

- `Host: knowledge.jingao.club` 返回 200；
- 未登记的 `Host: evil.example` 返回 421；
- 响应包含 CSP、`X-Frame-Options: DENY` 和内容类型保护；
- 经 `X-Forwarded-Proto: https` 进入时返回 HSTS；
- 请求体超过 2 MiB 返回 413；
- Docker 内部 `Host: web` 可通过，Uptime Kuma 监控不受白名单影响。
