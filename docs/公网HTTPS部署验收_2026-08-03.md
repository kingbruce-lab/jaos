# 京奥智库公网 HTTPS 部署验收（2026-08-03）

## 结论

`https://knowledge.jingao.club/` 已完成正式证书、Nginx 反向代理、FRP 本机监听收紧和公网验证，可以作为京奥智库员工公网入口。

## 链路

`员工浏览器 → HTTPS 443 / Nginx → 127.0.0.1:8000 / FRPS → NAS FRPC → NAS Web 3000 → 同源鉴权 API`

数据库和 Agent 没有在 NAS 宿主机或公网服务器上直接暴露端口。

## 配置边界

- 正式站点配置位于 `/etc/nginx-jingao/conf.d/knowledge.jingao.club.conf`；
- 专用 FRPS 服务为 `jadj_nas.service`；
- 专用 FRPS 配置增加 `proxyBindAddr = "127.0.0.1"`，避免 8000 绑定公网网卡；
- Nginx 向上游保留 Host、来源地址和 HTTPS 协议信息，流式响应关闭代理缓冲；
- 本轮没有修改该服务器上其他项目的 Nginx 站点或历史开放端口。
