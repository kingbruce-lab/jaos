# 京奥智库实施进展（2026-08-01）

## 当前结论

京奥智库 NAS 局域网首版已完成第六轮增量升级。知识进化不再只是一次性变化摘要：系统现已持久化登记维护资料及其已发布基线，按周期建立复核任务，保存候选、冲突、披露决策和确定性变更计划，并把“候选接受、对外披露、生成计划、完成复核、文档发布、更新基线”拆成独立的创始人闸门。

关闭复核不会推进资料截止线，调度器不会自动发布。评审 PPT 生成和把新文档发布为 `current` 仍是后续独立流程。

本轮仍只使用合成测试资料，没有导入真实公司资料、没有创建真实员工账号、没有把候选发布为 `current`。LLM 与 Embedding 四个出网开关保持关闭。

## 本轮完成

- 新增维护资料、复核任务、持久化候选和变更计划四类数据模型；
- 新增维护资料列表、候选基线、资料详情、手工复核、逐候选决策、变更计划、复核关闭和基线更新 API；
- 维护资料基线必须是当前、定稿、原件完整的已发布资料；基线更新只能指向直接替代旧基线且已经发布为 `current` 的文档；
- 夜间 `reconcile` 容器在原件对账后执行 `evolution-due`，只建立到期复核，不生成或发布公司资料；
- 每次候选决策和后续计划都会重新校验原件哈希、当前状态、定稿、项目、引用页码和冲突，防止“审过后源文件变化”被继续使用；
- 外宣候选、内部候选、拒绝、生成计划、关闭复核和更新基线均使用不同的精确确认短语；
- 高密级维护资料对低权限管理员完全隐藏，包含数量侧信道；
- Web“知识进化”页面已升级为持久化工作台，手机端表单、候选卡、证据和操作按钮采用单列布局；
- 原一次性 `POST /v1/evolution/digest` 保留为“不保存的临时检查”，不代替正式复核流程；
- Codex Skill 已加入全部持久化流程命令，并保留只走鉴权 API、不直读 NAS 或数据库的边界；
- 项目知识卡、结案提醒、来源完整性、候选发布闸门和受控 PDF 原页预览继续有效。
