# 京奥智库：AI 财务分析与项目管理第一阶段实施记录

日期：2026-08-12  
状态：第一阶段 MVP 已开发并通过本地测试

## 1. 已锁定的业务规则

### AI 财务分析

- 财务数据统一为 L4，仅以下账号可以访问：
  - 财务角色，且可见密级为 L4 或以上；
  - 管理角色，且可见密级为 L5。
- 银行流水只能由财务上传、修正、确认。
- 账外现金由财务、叶靖波、安利园填写。
- 支持 XLSX、CSV 银行流水，不限制上传星期，可连续导入一年以上历史数据。
- 原始流水文件保存在 NAS；财务数据不调用云端模型。
- 完全重复的银行流水文件和交易记录自动过滤。

### 项目管理

- 项目编号自动生成：`JADJ-年份-四位流水号`。
- 业务角色可以立项，并维护项目资料、收付款计划、过程进度和结案信息。
- 立项与结案都必须由以下三方全部通过：
  - 财务；
  - 叶靖波，对应生产账号 `founder`；
  - 安利园，对应生产账号 `jaanliyuan`。
- 其他管理+L5账号可以查看全部项目，但不会占用以上两个最高管理复核席位。
- 任一复核人退回后，项目返回业务修改；重新提交会创建新一轮复核记录。
- 财务复核实际收付款；项目经理维护计划和进度。
- 飞书提醒、自动回款预警、复杂项目排期不在第一阶段范围。

## 2. 第一阶段已经实现

### 财务系统

- 合并资金驾驶舱：银行余额、账外现金、合并余额、本期收入、本期支出、本期净流入。
- 近 26 周收支趋势。
- 多公司主体、多银行账户归档。
- 银行流水上传、解析、逐笔分类、项目关联、确认。
- 文件级 SHA-256 去重与交易级指纹去重。
- 账外现金登记与审计。
- NAS 目录：`财务系统/银行流水/公司主体/银行账户/年份`。

### 项目系统

- 项目立项草稿。
- 项目目标、周期、客户、成员、合同金额、收入预算、成本预算。
- 应收应付款计划、累计现金和最大垫资缺口。
- 财务登记实际收付款。
- 财务、叶靖波、安利园三方立项复核。
- 执行进度更新、风险与协调事项记录。
- 结案总结、实际收入、实际成本、未收未付金额。
- 财务、叶靖波、安利园三方结案复核。
- NAS 目录：`项目管理/项目编号/立项资料`、`项目管理/项目编号/结案资料`。

## 3. 数据和权限设计

- 复用现有本地账号、公司主体和审计日志。
- 财务与项目使用独立业务表，避免后续开发财务、人事、项目系统时互相污染。
- 所有权限在服务端 API 层验证，前端隐藏入口不作为安全边界。
- 金额统一使用定点小数，避免浮点金额误差。
- 关键操作写入 AuditLog。

## 4. 验证结果

- 后端测试：135 项通过。
- 财务专项测试：流水解析、文件去重、交易去重、修改、确认、驾驶舱计算、权限、账外现金。
- 项目专项测试：立项、三方通过、执行、结案、三方通过、退回与重新提交。
- 前端生产构建通过。
- ESLint 静态检查通过。

## 5. 下一阶段建议（本期不开发）

系统试运行后，根据真实录入情况再按优先级选择：

1. 各银行专用解析模板与导入错误修正向导；
2. 月度、季度、年度财务切换和公司主体筛选；
3. 应收账龄、应付到期、负债和利润分析；
4. 银行余额对账差异提醒；
5. 项目任务拆解、责任人、里程碑和附件中心；
6. 飞书回款预警和复核提醒；
7. 项目决算与银行流水自动关联；
8. 经人工验证后的 AI 财务解释与经营建议。

第一阶段的核心目标是先让真实数据进入同一条可审计流程，不提前构建尚未经过业务验证的复杂自动化。
