# 知识分类

知识分类由创始人在京奥智库中动态维护。不要把 Skill 内的示例分类当作固定枚举，也不要根据提示词自行创建分类。

开始分类检索、写作或上传前，调用：

```powershell
python scripts/jingao_knowledge.py categories
```

只使用返回结果中 `active=true` 的 `key` 作为 API 的 `category`。界面展示使用 `name`，持久化、权限和检索使用稳定的 `key`。分类重命名不会改变 `key`，停用分类不会删除历史项目或文件。

首版默认值包括电竞培训、电竞青训、电竞战队、电竞赛事、场馆运营和公司公共资料；它们只是初始化数据。创始人可新增、重命名、停用或重新启用分类。

分类与权限规则：

- 普通员工只能使用账户已授权的业务分类；公司公共资料仍受密级限制。
- 创始人与知识管理员可查看全部分类，但仍须遵守文档密级和出网策略。
- 未指定分类时允许跨已授权分类检索；不要为了“更准确”擅自缩小到一个分类。
- 一个项目使用一个主分类。需要表达交叉属性时，在输出中使用标签或说明，不要伪造新的分类键。
- 提案文件不等于项目已执行；分别记录 `proposal`、`executed` 和 `closed` 状态。
